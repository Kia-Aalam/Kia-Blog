about us

Kia Blog is a Django-powered blog platform built on top of a free HTML/CSS/Bootstrap template. While the front-end template (HTML, CSS, JavaScript, Bootstrap) was used as the visual foundation, the entire back-end was developed from scratch, including database models, views, authentication, and dynamic template rendering with Django's templating engine.


Key features implemented include a relational SQL database for posts and categories, a custom Django admin panel for content management, image upload handling for post thumbnails, view tracking for each post, and a secure user authentication system with Sign Up, Login, password hashing, and session-based authentication using Django's built-in authentication framework. This project was built to practice full back-end development, database design, authentication workflows, and integrating a static front-end with a dynamic Django backend.


Design: TemplateMo | Back-end Development: Kia Aalam
